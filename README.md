## 📦 Installation via ReaPack

The easiest way to install and stay updated:

1. In REAPER, go to **Extensions > ReaPack > Import Repositories...**
2. Paste the following URL:
   ```
   https://github.com/TheFancyWolf/fancy-scripts/raw/main/index.xml
   ```
3. Go to **Extensions > ReaPack > Browse Packages...**
4. Search for **"Fancy"**, right-click → **Install**, and click **Apply**.

## 🎚️ Scripts

### Fancy ParameterLink
Link FX parameters between tracks with Follow or Inverse modes and adjustable strength. Full ReaImGui interface with shared pickers, auto group-scan, global presets, live inspector, and settings modal.
- **Requirements:** REAPER 7.0+, ReaImGui

### Fancy Selected Track Meter
Real-time visual metering display for selected tracks with customizable colors, peak hold, and docking support.
- **Requirements:** REAPER 7.0+, ReaImGui

### Fancy Copy Fader to Send
Sets a Send volume to match the Main Track Fader. Useful for copying your Main Mix level to a Pre-Fader Headphone Send.
- **Requirements:** REAPER 7.0+
